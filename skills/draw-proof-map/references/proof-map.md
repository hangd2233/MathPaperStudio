# 数学语义与来源

- 依赖图 A→B 只表示 B 的证明使用 A；不是 A 单独蕴涵 B。多个结果及假设共同使用时，用 AND 汇合节点或明确分组展示共同前提，汇合节点同样有正文定位。
- 路线图正向推导使用实线箭头并标 forward；目标归约使用虚线空心箭头并标 reduce to。分类节点明确“ALL cases”或“alternative routes”，边标分支条件；全部情形需经 ALL 汇合，不能暗示择一即可。
- 保留对象、术语、假设、量词、参数范围、论证顺序和结论状态。归纳先画基例、归纳假设、步进和结论，不用未解释的循环充当证明。
- 缺失步骤用虚线框写 GAP / unproved，相关未确认边标 unverified（与目标归约不同：用点线及文字），不为连通补造关系。已有正文与 PROOF_MAP 不一致，只在 notes 和 working/ISSUES.md 记录，不修改源文件或原地图；绘图授权不授权补正文缺口。
- 外部结果分为“cited in manuscript; original not checked”和“original consulted this round”，后者记录实际原文位置及查阅范围。正文确实使用的外部结果仍可画出，但不可冒称已核验。
- notes 的节点和边表：稳定 id | 显示编号/关系 | 文件+label（无 label 时具体段落/行范围）| 状态。文件位置相对论文根；记录每份实际读取正文的 SHA-256 及范围。每条边有自己的来源定位；辅助标题/图例不是数学节点。

# 布局与更新

默认黑白、16–20px 以上标签、短行、层级分明、正交连线；颜色仅辅助。数学标签可用 `\(...\)`，根模型开启 `math="1"`；XML 正确转义，小公式优先。论文宏如 `\RR` 要显式替换为 `\mathbb{R}` 并记 notes，不假设自动读取 notation.tex。需在目标物理尺寸检查 PDF，出现原始分隔符、宏、空框或过小公式则不通过。

先读取原图（包含 Desktop 压缩 XML），baseline 后再改；稳定 id 用于最小差异编辑，保留未知属性、人工几何和折点。工具 check 不重写文件。若必须大幅重排，另存新版本并说明原因。仅重新导出时不要运行 layout、生成器或保存 XML。

换设备先确认同步完成及无冲突；在 CONTINUE 记录本轮写入结束。源图和参考同步，应用、用户配置和缓存本机保存。Prism 负责发起任务及阅读产物；源图在 Desktop 打开，不承诺内嵌画布。

用户要求定位原论文时，默认定位论文 PDF 正文，不跳 LaTeX 源文件。先确认固定稿 PDF 与图对应的正文版本一致，从 PDF 实际命名目标或文字位置提取页码和顶部起算的纵坐标，并核对对应标题。已安装 pdf-links 补丁的 Prism 使用 `prism-pdf://open?file=<URL编码的论文相对PDF路径>&sha256=<PDF内容指纹>&page=<从1开始页码>&y=<PDF点单位纵坐标>`。点击在项目内打开 PDF 并定位；版本指纹不符则提示更新链接，不猜测新版位置。结果卡及其 AND 卡定位相应结果陈述；分组入口须在 notes 明确。外部引用只能定位本文引用处，不冒充外部原文链接。

链接写入 draw.io object 的 link 属性，保留原 cell 的几何、样式和文字；导出后核对实际 PDF URI 注释。Prism 内部接收此协议，不注册系统协议，不保证 Desktop 或其他 PDF 阅读器能跳转。其他设备需另行安装验证。仅用户明确要求源码导航时才使用旧 prism-source 协议；不能将其作为 PDF 正文跳转的替代。

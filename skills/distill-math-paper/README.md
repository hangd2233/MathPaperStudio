# distill-math-paper — 论文选材与定界

本技能用于 MathPaperStudio：从 Danus 围绕一个大问题产生的多轮阶段报告中，选择有共同主线、证明材料可追溯的一篇论文，而非按报告顺序拼接全文。它可以只做选材，也可以在用户明确要求后衔接写作。

## 安装范围

这是本地项目技能，不是 Danus 插件，也不是 ChatGPT 托管插件。技能包只包含说明和调用配置，不包含模型服务、凭据或自动执行脚本。

在坚果云同步的 `MathPaperStudio/skills/distill-math-paper/` 保存技能母本。在实际运行 Codex 的项目根目录，将该文件夹复制为 `.agents/skills/distill-math-paper/`。实际加载入口依赖工作目录与仓库根目录；打开单篇论文时，应确认该项目能够发现本技能。不要把母本目录的存在当作已经完成安装。不要依赖跨设备符号链接，也不要在同一加载范围的多个层级部署同名副本。

本包通过 `agents/openai.yaml` 关闭隐式调用：日常改一句英文不应触发整批报告扫描。需要使用时明确输入 `$distill-math-paper`。安装后在技能选择器确认其可见；本包未代替你在实际 Codex 环境中做运行验收。

## 使用

### 仅选材

```text
$distill-math-paper
阅读我指定的这组 Danus 阶段报告，只选择最适合组织成一篇论文的部分。
按数学贡献与证明依赖选择，不按报告编号拆分。
提出一个首选方案，必要时最多列两个实质不同的备选；说明精确的主要结果、
选入与排除的范围、证明来源、后续修正和缺口。此次不生成论文正文。
```

### 选材并开始写作

```text
$distill-math-paper
从我指定的阶段报告集合中选择一篇主线清晰、证明材料尽量完整的数学论文。
提出并记录首选方案后，直接衔接 compose-math-paper 形成英文 LaTeX 工作稿和 PDF；
不要按条审批，也不要擅自生成多篇论文。
不要求解决整个大问题；但不要把猜想、旧版本结论或未核对的“已完成”状态
写成已证定理。保留来源与人工修订，缺口在相应正文位置及 ISSUES.md 中明确标记。
```

调用时补充本机实际可访问的报告目录或文件选择；不要把示意路径当作真实目录。

## 与既有技能的关系

`import-research → distill-math-paper → compose-math-paper → revise-math-paper → prepare-paper-release`

导入负责原样保存材料；本技能负责判断写什么；成稿负责如何组织和表达。现有正文、已接受版本与选题决定优先保留，重新选材不得静默改变它们。

初步判断可保存在报告集合下的 `selection/`；选定后，写作交接复用论文已有的 `BRIEF.md`、`working/PROOF_MAP.md`、`working/ISSUES.md`，不建立新的结论数据库。运行完成后更新 `CONTINUE.md`。

## 建议验收情形

使用小型明确标为合成材料的测试集合，检查以下行为，不要把合成材料带入真实论文：

- 后一报告修正了先前主定理：使用兼容的修订结论，同时保留早期仍有效的证明材料。
- 不同报告含有同一篇论文的定理、引理和例子：按证明依赖组合，不按报告各写一章。
- 某引理只在较窄参数范围成立：不扩大主定理范围，也不遗漏必要假设。
- 大问题尚未完成但一个子问题证据充分：可以推荐该范围，不必等待所有分支结束。
- 不存在可支持的主要结论：说明具体缺口，不编造完整证明或投稿成熟度。
- 用户只要求润色：不隐式启动本技能，不改变论文范围。
